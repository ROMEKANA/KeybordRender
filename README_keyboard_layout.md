# E-YOOSO Z-88 キー配列 YAML の読み方

対象ファイル：`E-YOOSO_Z88_layout_v1.0.5.yaml`

このYAMLは**変更後のキー表示**をそのまま描画するためのデータです。元の刻印・変更履歴・色分けなどは含みません。キー数は **109個**です。

## 構成

`groups` の下に3つのキー群があります。

- `main`：Esc、Fキー、文字キー、修飾キー、スペースキー
- `navigation`：Print Screen、編集・移動キー、方向キー
- `numpad`：テンキー

各群の `-` で始まる要素がキー1個に対応します。

```yaml
- id: Space
  label: Space
  row: 5
  col: 4
  x: 4.75
  y: 5.5
  w: 3.25
  h: 1
```

| 項目 | 意味 |
|---|---|
| `id` | キーの一意な識別子。右Windowsは `WinRight` のように区別します。 |
| `label` | キー中央に描く文字。変更後の表示のみ記載しています。 |
| `row` | 最上段を `0` とする段番号（全部のキー群に共通）。 |
| `col` | **同じキー群・同じ段**で左から数えた順番。`0` 始まり。 |
| `x`, `y` | キー外形の左上座標。単位は `u`。右・下が正方向。 |
| `w`, `h` | キーの幅と高さ。単位は `u`。普通の文字キーは `1 × 1`。 |
| `outline` | 特殊形状のキーだけに付く、キー左上を基準とした外周頂点。通常のキーでは省略。 |

`1u` は標準キー1個分の配置ピッチです。**実測したミリメートル値ではありません**。`col` は並び順を表すもので、物理的な列位置は `x` を使います。例えば段によってキーの開始位置がずれていても問題ありません。

## Enter の特殊形状

メイン側のEnterには次の `outline` が付きます。

```yaml
- id: Enter
  label: Enter
  row: 2
  col: 13
  x: 13.5
  y: 2.5
  w: 1.5
  h: 2
  outline:
    - [0, 0]
    - [1.5, 0]
    - [1.5, 2]
    - [0.25, 2]
    - [0.25, 1]
    - [0, 1]
```

頂点はこの順に結んで閉じます。これで**上側1.5u・下側1.25u、下側の左端が0.25u右にずれた、上下がつながる形**を再現できます。`outline` の座標は相対値なので、描画時は各頂点に `x`, `y` を加算します。`w`, `h` は全体を囲む大きさです。**2つの別キーとして描かず、1つの連結した形にしてください。**

通常キーは `x, y, w, h` から長方形を描きます。テンキーの `+` と `Enter` は `h: 2`、テンキーの `0` は `w: 2` で表現します。

## 編集・描画時の注意

- 文字を変えるだけなら `label`、識別子を変えるなら `id` を編集します。
- 大きさを変える場合は `w` / `h` と、必要に応じて後続キーの `x` を調整します。
- 図の間隔・背景色・フォントは**描画プログラム側**で決めます。このYAMLには含めていません。
- 現在の寸法は以前のv1.0.4を引き継いだ**モデル座標**です。実機を測定していない部分は今後の照合対象です。
